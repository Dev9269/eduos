📖 EduOS User Manual

Version 1.0.0 | Educational Operating System for Engineering Institutions

1. Getting Started

Logging In

EduOS boots to the SDDM login screen. Select your user and enter the password. Passwords are generated randomly at install time — the lab admin can find them in /etc/eduos/credentials.conf (root-only).

UsernamePasswordPurpose
studentgenerated (see credentials.conf)Daily learning and coursework
examgenerated (see credentials.conf)Restricted examination environment
admingenerated (see credentials.conf)Lab administration and management

Desktop Overview

EduOS uses KDE Plasma configured with a Windows 11-like layout:

  • Floating centered taskbar at the bottom
  • Application Menu in the bottom-left corner
  • System Tray on the bottom-right (network, sound, clock)
  • Desktop is clean — no icons by default
  • Right-click on desktop for context menu
💡 Tip: Press Alt+Space to open KRunner (application launcher/search). Press Alt+F2 for a command runner.

4. Using Exam Mode

Starting an Exam

  1. Log in as student or exam
  2. Run eduos-exam or click the Exam Mode icon on the desktop
  3. Enter your Security Key (provided by invigilator)
  4. Enter your Name and Student ID
  5. Click Authenticate & Start Exam

During the Exam

  • The exam runs in full-screen mode with no window decorations
  • A timer shows remaining time in the top-right corner
  • Answers are auto-saved every 30 seconds
  • Use the question list on the left to navigate
  • Answered questions are tracked in the progress indicator
  • Print Screen, Alt+Tab, and Super keys are blocked
  • Internet is blocked during the exam (restored on exit)

Submitting

  • Click Submit Exam when finished
  • If the timer expires, the exam auto-submits
  • Answers are encrypted and saved locally
  • A PDF result is generated automatically
⚠ Important: The exam user has a restricted shell that only launches the exam application. Regular terminal access is not available for this user.

7. System Administration

Lab Management

Open the Admin Center (eduos-admin) to:

  • View system resource usage (CPU, memory, disk, network)
  • Manage lab machines
  • Install/remove software
  • Start and stop examination sessions
  • Send announcements to lab machines
  • Generate reports

Security Hardening

Run sudo eduos-hardening to apply all security measures:

  • Enable firewall (UFW)
  • Lock root account
  • Disable SSH root login
  • Set secure home directory permissions
  • Enable process accounting for audit trails
  • Disable unnecessary services

9. Troubleshooting

Learn Hub not loading

Run: systemctl --user restart eduos-learnhub

Check if it's listening: ss -tlnp | grep 5050

Docker not working

Ensure Docker is running: sudo systemctl status docker

Add your user: sudo usermod -aG docker $USER (log out and back in)

VM feels slow

Disable compositing: systemsettings → Display → Compositor → Disable

Check memory: free -h | Disk: df -h

Reset user password

sudo passwd student (or exam, admin)

10. Backup & Restore

Create Backup

Run: bash ~/EduOS/Scripts/create-backup.sh

This saves system configurations and package lists to ~/EduOS/Backups/

Create System Image

Run: sudo bash ~/EduOS/Scripts/create-system-image.sh

Creates a compressed full-system image for deployment to other machines.

⚠ Important: Always take a VM snapshot before making major system changes. EduOS keeps a complete changelog at ~/EduOS/CHANGELOG.md.
